# 负片预览自由点曲线（2026-10-06）

用户要求曲线不再只有三个固定横坐标的点，并支持双击单点复位和自由新增控制点。本轮把固定阴影 / 中间调 / 高光锚点改为可编辑点曲线，沿用当前校色面板、通道颜色、实时预览和重置入口。

## 操作

- 默认是两个黑白端点连接的中性直线。
- 轻点图表空白处，在触点的输入 / 输出位置新增控制点；轻点已有点选中它。
- 拖动内部点，可同时改变输入和输出。相邻点的输入不能交叉，输出可以自由升降，不再强制整条曲线递增。
- 黑白端点的输入固定为 0 / 1，输出可上下移动，支持抬黑、压白。
- 双击控制点，把该点输出恢复到当前输入对应的中性对角线；保留该点横坐标和其他点。端点分别恢复为 (0, 0) / (1, 1)。
- 长按内部点删除；黑白端点不可删除。
- “重置当前曲线”清除该曲线的内部点并恢复中性直线。R / G / B 可分别编辑；RGB 入口沿用同时应用到三个通道的共同编辑方式。

新增点需要等待系统确认它是单击，避免双击复位时误加点。拖动已有点保持连续更新；从图表空白处开始的滑动可交给外层参数面板滚动。切换通道、重置、应用新校正、改变尺寸、隐藏面板或离开页面时取消未完成的手势及延迟点击；多指触碰也中止当前单点编辑。

输入最小间距为 0.01，最多 32 个点（含两个端点），避免重复横坐标和过密点造成数值问题。点太近或已达到上限时不新增。选中点显示较大的标记和外圈；面板内保留简短操作说明。

## 处理与实现

`FilmNegativeCurve` 保存归一化的不可变点快照，按输入排序并处理非有限值；返回给界面的点列表不能改写渲染器已经持有的曲线。曲线变化时预计算插值导数，曲线比较和哈希按点的值计算，继续用于原有 LUT 缓存。

图表与密度转换共用形状保持的三次 Hermite 插值。它经过每个控制点，在相邻输出之间避免额外过冲；递增点保持递增，有意设置的峰谷也能保留。在白点以上使用最后一段的线性斜率继续输出，保持原有高光余量机制；用户主动设定平坦或下降的末段时，延伸也随之变化。GPU 仍消费原有 RGB LUT，没有更换着色器或新增原生依赖。

数学方法核对了 [SciPy 的 PCHIP 官方说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.PchipInterpolator.html)，包含相邻割线的加权调和导数和端点处理；本项目自行用 Kotlin 实现，没有复制 SciPy 源码或引入其运行时依赖。此处借鉴点曲线的交互方式，不宣称复刻 Lightroom 的全部曲线或颜色处理。
