# 负片静帧选区交互（2026-10-05）

用户反馈拖出选区不方便，要求类似照片编辑器的边、角点与旋转操作。照片模式现改为一个预置的可编辑矩形框，不再用单指划出新框；顶部负片预览标题同时按用户要求删除，只保留返回入口，减少中央摄像头挖孔遮挡文字的问题。

## 操作

- 拖动某条边：沿该边的法线调整范围，对面的边固定。
- 拖动角点：同时调整宽、高，对角点固定；不强制 135 比例，可框选其他画幅。
- 框内拖动：移动整个框。
- 框外单指滑动：围绕框中心旋转，原图不随之旋转。
- 双指：缩放 / 移动原图；收起一根手指后不会误接续成选区拖动。

选区内增加三分网格，边中点及角点有可见操作点，框外暗化。提示在自动选区或分析失败后仍显示。保留自动选区、取消、确认，以及高级片基取样的椭圆圈选操作。

当前框是可旋转矩形，不做四角独立透视变形；边与角点改变尺寸但保持直角。操作受原图边界与最小尺寸限制，不能拖成反转、交叉或超出图像的框。框接近原图边界时旋转会受限，可先缩小或移动框再旋转。尺寸很小的框会缩小边 / 角点命中范围，避免这些区域覆盖整个框；可双指放大原图后微调。

## 确认后的分析

选区几何使用原始图片像素坐标计算旋转，再转换为归一化四角，避免在竖幅图片中旋转失真。缩放原图不改变实际选区的图像坐标。

确认时按真实四边形内部统计 Dmin / Dmax 和颜色，不以旋转后的外接矩形代替内容。匹配原有照片检测候选时，比较实际选区掩膜的重叠；复用候选内部掩膜仍要与用户范围相交。没有可复用候选时，沿旋转框的平行边检查附近片基；只用最近邻原始像素，不把插值颜色作为片基。证据不足时保留已有内容估计与失败提示。

自动选区后未经编辑直接确认，仍能复用原自动识别结果。编辑过后重新分析真实选区。一键反相保持一次识别后直接应用的流程，不新增用户选择。
