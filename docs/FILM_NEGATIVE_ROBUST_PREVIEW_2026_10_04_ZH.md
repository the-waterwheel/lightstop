## 一键流程

主入口为 **一键识别并校正**。用户点击一次后，应用确认曝光和白平衡锁定，截取一帧未经负片 LUT 处理的原图，自动选择照片、判断彩色或黑白处理、寻找附近片基、分析影调与可用中性样本，直接显示校正后的正像。

按用户反馈，最终版本取消三帧一致性窗口和位置跟踪。照片与片基来自同一静止帧，无需在手机移动时反复寻找同一位置；成功得到的片基、密度端点及颜色校正随后持续用于 GPU 实时预览。相机曝光、白平衡、处理曲线或会话真正改变时才让参考失效，避免把旧输入条件下的参数应用于新输入。仍需避免截取时的明显运动模糊，但移动或转动本身不再是等待多帧确认的失败条件。单次取帧及分析有 6.5 秒超时，没有后台持续重识别。

这条流程不打开静止帧编辑器，不要求确认选区、选择画幅、挑片基候选或预选彩色/黑白。多张照片同框时，以实际照片面积和距画面中心的距离自动择优。成功后显示亮度、中间调、饱和度、色温、色调、校色强度及密度端点等微调项；反相前后对比和黑白覆盖开关也在结果调整区。曝光锁定开关移到高级调整中。

“手动选区（备用）”是独立入口。自动证据不足时保留已有有效结果、恢复按钮并提示保持片边后重试，不强制转入手动选择，不把未知片基伪报为成功。

## 审查发现及修复

| 原问题 | 影响 | 本轮处理 |
| --- | --- | --- |
| 片边按横行/竖列支持率判断；旧测试的旋转仅为 90° | 任意角度、弯曲和透视形变容易漏检 | 新增 `FilmNegativeShapeDetector`，以密度连通区域及周围片边支持验证照片，不限定直边或画幅比例 |
| 使用照片外接矩形统计 | 倾斜后的角落混入裸背光、片边及片夹 | 使用实际形状掩模，只在内缩一像素的照片区域统计；填补封闭内部细节，保留非矩形外轮廓 |
| 每帧用单像素片基采样框的 IoU 校验 | 手持移动就让三帧确认失败 | 改为截取一帧、识别一次并复用校正参数；自动入口不再调用多帧窗口，不依赖几何跟踪 |
| 多帧取样与重复计算 | 延迟增加，也可能混入移动后的其他照片 | 照片和片基来自同一确认锁定的原图；没有可靠结果时明确结束、恢复按钮，允许再次一键重试 |
| 自动识别依赖预选的黑白开关 | 一键动作仍可能要求用户先选择模式 | 同时搜索橙色和中性片基；中性候选还须验证照片相对密度大体中性，排除白色灯箱包围彩色胶片的误判 |
| 静止帧自动选区确认时重新按矩形计算 | 预览标出的形状与最终分析范围不一致，重复计算 | 缓存该静止帧的自动结果；未修改选区直接使用；绘制真实轮廓，分析期间禁止修改选区 |
| 静止高分辨率帧每个候选都重复进行较大区域统计 | 候选多时延迟高 | 自动分析统一在长边 256 的原图样本上进行；有界候选池与连通区域验证，GPU 视频管线保持原有路径 |
| 多张照片同框时先对全部候选计算影调和校色 | 做了最终没有使用的统计 | 按面积及中心位置先排序，只分析首个可用照片；影调不足时再尝试下一个 |
| 手动附近片基可由单侧色带证明 | 平滑照片渐变可能被当成物理片基 | 手动矩形的保守备用检测也要求至少两侧支持；没有可靠参考则明确使用内容估计 |
| 成功后切到原图会隐藏对比按钮与微调项 | 无法直接切回正像 | 面板可见性由有效参考决定；对比不清空结果，重置或相机参考失效时才收起 |
| Android 像素循环使用泛型范围迭代器 | 桌面 JVM 结果无法反映实机的大量临时分配 | 像素有效性、颜色相似与邻域检查改为直接通道比较，保持阈值不变；实机增加 Debug 专用耗时日志，Release 中移除 |

小工具页的负片图标纹样已由白色改为黑色，包含边框、齿孔和内部图案。此前安排的 08:00 修改在本轮补做，纳入相同测试包；独立提交为 `d2e22d6`。

## 算法及边界

颜色候选采用量化直方图和邻域一致性，保留细窄的斜向片边。每类最多 12 个颜色种子，每种颜色最多验证 8 个较大的连通区域，避免在纹理/噪声图上无界扩张工作量。片基需在照片边界的多个方向持续出现，并通过局部颜色离散度检查；不以最亮像素或橙色这一条条件认定片基。

几何检测不使用 135 专属的齿孔或 3:2 比例先验。掩模随实际轮廓变化，可以容纳弯曲和梯形。这里没有做底片展平、透视矫正或强行拉直显示；目的在于从这些姿态中正确取得预览分析范围。

处理保留线性化后的相对密度 `log10(Tbase/T)`、共享密度分位数、有限且单调的通道校正和现有 GPU LUT。改进重点是这些统计实际读到的像素及参考可信度。没有可靠中性轴时仍完成去片基、反相与影调，保守保留颜色，不为“自动”而强迫照片变中性。黑白/彩色判断是观测到的片基与内容属性，不是胶卷品牌识别；特殊染色黑白片等仍可在结果中覆盖显示模式。

自动流程需要看见足够的未曝光片边。完全裁掉片边、严重过曝、明显反光、相邻照片相连、极薄片边缩小后消失或主体与片基不可区分时，传统图像方法不能保证唯一正确判断。输入仍是相机 ISP 的 8-bit 预览，无法恢复已裁切通道或保证扫描级色彩。没有引入机器学习模型。
