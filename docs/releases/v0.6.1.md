# lightstop 0.6.1

## 中文

- 恢复 0.5.0 使用的 r2 精简 OpenCV。审计确认当前 Zone 与新增运动视差估距所需接口均已包含；负片预览没有新增 OpenCV 模块需求。
- 默认分别生成 arm64、armv7、x86_64 APK，并保留通用包；AAB 构建自动关闭 APK 分包。
- 分架构包功能相同，沿用 0.6.0 的发布签名，可直接升级。大多数手机使用 arm64；不确定架构可选通用包。

版本为 0.6.1 / 12，要求 Android 9 及以上。588 项测试通过；签名、版本、r2 库内容和 16 KB ZIP / 64 位 ELF LOAD 对齐已核验。尚未完成 r2 与 r4 的同机性能对照，也未在 16 KB 系统上实测。0.6.0 保留不变。[验收记录](../RELEASE_0_6_1_VALIDATION_ZH.md)。

## English

- Restored the compact OpenCV r2 runtime used by 0.5.0. Its Java/JNI surface covers current Zone tracking and motion-distance calls; negative preview needs no additional OpenCV module.
- Build separate arm64, armv7 and x86_64 APKs plus a universal APK by default. Bundle tasks automatically disable APK splits.
- All packages have the same features and use the 0.6.0 signing key for upgrades. Choose arm64 for most phones, or universal if unsure.

Version 0.6.1 / 12; Android 9+. All 588 tests passed. Signing, metadata, r2 libraries, 16 KB ZIP alignment and 64-bit ELF LOAD alignment were verified. Same-device r2/r4 performance comparisons and runtime testing on a 16 KB system remain pending. The published 0.6.0 is unchanged.
