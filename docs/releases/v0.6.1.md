# lightstop 0.6.1（候选 / Candidate）

## 中文

- 恢复 0.5.0 使用的 r2 精简 OpenCV。审计确认当前 Zone 与新增运动视差估距所需接口均已包含；负片预览没有新增 OpenCV 模块需求。
- 默认分别生成 arm64、armv7、x86_64 APK，并保留通用包；AAB 构建自动关闭 APK 分包。
- 分架构包功能相同。未签名构建约为 arm64 16.71 MiB、armv7 12.62 MiB、x86_64 21.03 MiB、通用 42.59 MiB。

## English

- Restored the compact OpenCV r2 runtime used by 0.5.0. Its Java/JNI surface covers current Zone tracking and motion-distance calls; negative preview needs no additional OpenCV module.
- Build separate arm64, armv7 and x86_64 APKs plus a universal APK by default. Bundle tasks automatically disable APK splits.
- All architecture packages have the same features. Unsigned sizes: arm64 16.71 MiB, armv7 12.62 MiB, x86_64 21.03 MiB, universal 42.59 MiB.

Version 0.6.1 / 12. Requires Android 9+. Signature and final asset hashes must be checked after maintainer signing. Same-device performance comparisons remain pending; no performance equivalence claim is made. The published 0.6.0 remains unchanged.
