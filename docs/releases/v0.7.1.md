# lightstop 0.7.1

Android 9+，versionCode 14。

- 修复测光校准启动超时、旧 RAW 回调和输入源重试问题，改善失败后的预览恢复。
- 改进 Clear 连续测光稳定性，全局模型推荐曝光使用半档负片偏置。
- 新增实时距离与景深显示、胶片宽容度卡片和包装配图。
- 自动测距为试验性功能，准确性依赖设备和拍摄条件。
- 整合基线通过 871 项单元及 Robolectric 界面测试。相机兼容性和测光精度仍需真机验证。

Improved calibration recovery across RAW, YUV and preview streams, capture callback ownership, and continuous metering stability. Added live distance/DOF readouts and film latitude cards. Automatic distance remains experimental and device-dependent.

Use the same release signing key as previous versions to support upgrades.
