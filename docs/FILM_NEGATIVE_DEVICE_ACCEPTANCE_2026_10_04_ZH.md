# 负片预览实机验收（2026-10-04）

状态：**已完成部分实机验收**。V2405A / Android 16 的多条底片袋场景已验证。最终版本采用单帧识别，没有位置跟踪；其他画幅、明显弯曲和运动模糊下的真实成功率仍待测。下表保留完整验收计划，实际通过的项目与证据见末尾记录。

## 安装与记录

最终通用 Debug APK 放在本工作树的 `dist/negative-preview-2026-10-04/`，支持 arm64-v8a、armeabi-v7a、x86_64，最低 Android 9。包名 `com.lightmeter.rawmeter`，版本 `0.5.0`（10），由本机开发证书签名。它用于测试，不是正式发布包。

当前包包含单帧校正、实机分配优化和后续生命周期修复，大小 49,527,228 字节（47.23 MiB）；SHA-256 为 `78ad3594cd3e615bfb11c76e1c5dae934279dadb3a32cfb469fa82b70d990300`。已通过 513 项单元测试、Lint（0 错误 / 66 项现有警告）及 APK v2 签名检查。手机实际安装 APK 已拉回验证，与交付文件哈希一致。验收时以此哈希区分其他分支的 0.5.0 安装包。

连接手机并打开 USB 调试，接受手机的调试授权后：

```powershell
adb devices -l
adb shell getprop ro.product.model
adb shell getprop ro.build.version.release
adb install -r dist\negative-preview-2026-10-04\lightstop-negative-preview-debug.apk
adb logcat -v threadtime > dist\negative-preview-2026-10-04\device-logcat.txt
```

`-r` 仅在签名一致时保留数据升级。如果出现签名不一致，保留安装失败和现有安装，先决定如何安排测试环境；不要直接卸载已有应用。测试前记录机型、系统、镜头、照明、底片类型和 APK SHA-256。
