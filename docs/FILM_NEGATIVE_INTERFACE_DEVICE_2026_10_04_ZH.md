## 失败、警告与未完成检查

- 现场操作日志中也有识别拒绝；最后一次长焦近距离构图只显示部分照片和边缘时，返回 `accepted=false`（234 ms），保留原预览并显示重试提示。部分早期操作混有用户移动或点击，没有统一的标注样本和操作条件，因此不统计“成功率”。失败原因尚未从原始帧标注中确认；不能直接归结为移动、画幅或弯曲。
- 自动选区已验证一个现场候选的编辑边界显示；没有证明全部多条底片场景都能选到用户期望的照片。一次自动流程仍选取一张目标照片。
- 后台恢复检查未完成：通过 ADB 启动入口尝试返回时，截图曾停留在桌面；再次启动后到达测光主页，未确认回到原负片页面并保留校正。这组操作不能记为负片后台恢复通过，也不足以确定是应用恢复缺陷还是测试启动方式影响。
- 收集到的应用 PID 日志未发现 `FATAL EXCEPTION`；仍有 Android Camera2 `onClosed` 向已退出 Handler 线程投递的警告，调用栈来自框架的 `CameraDeviceImpl$CameraHandlerExecutor`。本轮没有修复或宣称消除该警告，需单独复测相机关闭与后台恢复时序。
- 未验收：持续移动与运动模糊的识别率、受控弯曲、黑白及非 135 画幅、深色 / 横屏 / 左手 / 放大字体、前置镜头、12 秒切换超时、全部 RGB 通道对齐滑块、基础对比度、GPU / CPU 数值一致性、连续快速操作及内存压力恢复。

后续应以标注真实照片范围和片基的样本集评估准确率；优先补做后台恢复、移动 / 弯曲 / 不同画幅检查。本轮不新增机器学习依赖，自编译 OpenCV 继续暂停。
