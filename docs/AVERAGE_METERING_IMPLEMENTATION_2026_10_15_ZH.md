# 全局测光：实现与验证记录

初版日期：2026-10-15；名称与模式范围更新：2026-10-17。分支：`codex/independent-metering`。只在本对话的工作树实施；其他对话的工作树未作修改。

## 使用入口

在“测光设置 → 测光区域”中选择第四项“全局测光”；英文为 `Global`。此前名称为“平均测光”，保留 `MeteringMode.AVERAGE` 作为已有设置的持久化标识，旧选择直接兼容。选择会随原有设置保存。Normal 取景器以整幅边框表示测量范围。点测光、中央重点和按角度测光继续走各自的局部算法。

新模式使用当前可见画幅和电子变焦确定的范围。RAW、YUV、显示预览三个来源分别保留自身解码、曝光元数据和校准身份。YUV 不能覆盖完整可见画幅时沿既有流程尝试显示预览，不以局部测量冒充全画面。

### Normal 与 Zone

全局测光算法仅在 Normal 中运行。Normal 选择全局测光后进入 Zone，实际模式、设置高亮和取景标记均切换到按角度测光，沿用该镜头已保存的角度；没有记录时仍使用既有默认角度。返回 Normal 自动恢复全局测光。

`MeteringModeSelection` 负责区分已保存的 Normal 选择和临时 Zone 选择；`MeterLayout` 在模式切换完成时更新作用范围。Zone 内更改测光模式或其他设置不会把 Normal 的全局选择写成按角度/点测。再次进入 Zone 仍以按角度测光作为默认。其他原有局部模式继续保持原来的共享选择行为。

Zone 单点和批量请求都在调用相机前解析为局部模式；分析层拒绝带 Zone 点位的全局统计请求，防止全画面推荐值误写成局部读数。来源校准单独使用点测，不执行全局曝光建议。连续减曝光重拍仍适用于两种界面的实际局部/全局测量：局部每次 `5 EV`，Normal 全局每次 `3 EV`，没有因本次范围更改而恢复旧次数上限。

既有兼容模式的角度精度限制保留：其预览分辨率不足以支持有效角度测光。若在兼容模式下进入 Zone 并默认到按角度测光，实际测量前使用现有提示要求切换到高精度或稳定模式，不以点测冒充角度测光。

## 确认的算法

先对局部线性亮度扣黑、归一化并作适用的颜色/暗角/来源校正，结合该帧曝光、ISO、光圈换算为区域 EV100。画幅内面积等权，不依位置、主体或场景赋权。

令 `Q(p)` 为按亮度排序的区域 EV 分位函数：

```text
B = integral(Q(p), p=0.05..0.95) / 0.90
U = integral(Q(p), p=0.98..0.995) / 0.015
h = 2.5 EV
c = 0.5 EV
delta = clamp(U - B - h, 0, c)
recommendedEv100 = B + delta
R = max(0, U - B - delta - h)
usedEv100 = recommendedEv100 - userExposureCompensationEv
```

`B` 保留为测得场景基准；自动减曝光量与用户补偿分开保存，进入现有曝光解算时各应用一次。常规反差下 `delta=0`，最大自动减曝光为半档。`R` 只用于提示反差，不解释为某款胶片的精确溢出量。

没有学习模型、训练样本、场景分类、主体识别或胶片曲线拟合。设计与研究来源见 [算法方案](NEUTRAL_EVALUATIVE_METERING_DESIGN_2026_10_15_ZH.md)。

## RAW 饱和重拍

- 采样单元任一 Bayer 通道达到扣黑后归一化白点的 `0.985` 即记为截断；区域仍留在面积分布中。
- 截断面积超过 `0.5%` 时，认为已影响实际使用的亮端区间，连续触发重拍：每次再降低 `3 EV`，即相对初始采样曝光的 `−3、−6、−9、−12 EV……`；每级一帧，逐帧检查，直到亮端不再被截断。“全局测光”不设两次次数上限。
- 每次提交前检查新的曝光请求能否继续降低：手动曝光比较快门时间与 ISO 的乘积，自动曝光比较实际可设置的 AE 补偿。相机达到曝光下限或不支持继续降低时，结束重复请求；仍截断的亮端保持“未确认”，有可信基准则返回基准，没有则测量失败。
- 这些变化是手机 RAW 的测量曝光。外部相机的最终自动曝光修正仍最多半档。
- 重拍保留此前可信的 `B`，只用短曝光恢复亮端统计；若此前无可信基准，可从后续有效帧建立。每帧先按自身实际曝光元数据换算为 EV，不能直接混合 RAW 数值。
- 截断超过 `5%` 或落入信号底的面积超过 `5%` 时，该帧不能提供可信 `B`。没有任何可信基准就返回测量失败。已有可信基准但最终亮端仍不可确认时，返回基准并显示“亮部未确认”，不伪造亮部保护结果。
- 暗部落底不会触发更短曝光。高光面积不超过忽略的最高 `0.5%` 时，不单独为这些亮点重拍。

沿用既有配对、单请求在途、每级超时、取消、关闭图像和恢复预览机制；重拍次数按实际饱和状态和相机控制范围决定，没有加入 HDR 合成或长期采集。

### 点测光、中央重点、按角度测光的后续调整

按用户后续要求，三种局部模式改为当前测光区域饱和时连续每次降低 `5 EV`，相对初始采样曝光为 `−5、−10、−15 EV……`，直到测量统计恢复。这里的饱和依据为已有区域采样的通道中位数：任意一个达到 `0.985` 就触发，避免单个颜色通道已经截断却仍给出偏差读数。画幅其他位置的高光不单独触发局部重拍。中央重点在中心区域与较大区域加权混合前分别检查，防止饱和被混合值掩盖。

局部模式也在每次提交前检查相机能否继续降低曝光；达到下限仍溢出时返回明确错误，不把该读数作为有效测光结果。全局测光仍按自身亮端分位区间判定，步长保持 `3 EV`。

速度处理复用现有统计，不添加图像扫描或等待：一发现饱和就立即转入短曝光，不等当前 ISO 对应的原始多帧计划完成；每次重拍固定一帧且不追加同曝光降噪帧，图像关闭后继续下一请求。测点坐标/匹配结果继续复用。Zone 批量点位共用每次重拍，已在较长曝光读准的点保留原结果、跳过后续分析，防止较暗点被后续短曝光淹没，也避免逐点重复捕获。

这些控制路径减少可避免的请求与重复处理；每帧 HAL、传感器模式和预览恢复仍有固定成本，未将 `5 EV` 的亮度缩减比例解释为总延迟缩减比例。实际耗时仍需真机验证。

## 职责边界

| 位置 | 职责 |
| --- | --- |
| `EvaluativeMetering.kt` | 分位区间积分、可信度、纯曝光公式、逐帧摘要融合 |
| `EvaluativeFrameAnalyzer.kt` | 借用已有 RAW/YUV/Bitmap，处理可见范围和光度输入 |
| `evaluative_raw_sampler.h`、JNI 桥 | 一次扫描完整 Bayer 单元，输出局部亮度及截断证据 |
| `RawLightMeter`、`CompatibleLightMeter` | 保持原采集所有权，连接统计结果和既有重拍流程 |
| `MeterState`、独立展示模块 | 区分基准、自动修正、用户补偿和提示 |
| `MeteringModeSelection` | 保存 Normal 的全局选择，管理 Zone 临时角度/局部选择与返回恢复 |
| `CameraController` | 仅新增三行视口/预览几何数据透传，无新算法或状态机 |

RAW 取最多 `32768` 个完整 Bayer 单元；处理后来源取最多同量均匀样本。初稿提到的 EV 分桶未采用：实现对有界样本排序，按分位边界的部分面积作精确区间积分，避免额外的桶宽误差。它仍是稀疏采样估计，不声称逐像素全图统计。

多帧先分别生成摘要，对可信 `B`、`U` 分别取中位数，再作一次曝光决策；不声称等价于合并所有像素分布。处理后响应校准和暗角表每帧取一次快照，避免每个样本重复读取设置。Zone 将全局选择映射为按角度测光，校准用途独立映射为局部点测，自动亮部策略不写入校准锚点。

本分支先读取 main 与其他对话近期分支，并快进至相机职责分离分支的 `9b74d85`，再在此基础上实现；架构阅读记录见 [项目结构记录](INDEPENDENT_METERING_ARCHITECTURE_2026_10_15_ZH.md)。新增实现依据数学定义独立编写，没有复制参考项目代码，没有新增第三方依赖。
