## 自动选区的轮廓问题

之前手动编辑器直接画出了分析使用的像素掩膜。掩膜可能沿图像细节或弯曲边缘形成不规则轮廓，适合排除片边、齿孔等统计干扰，但不适合作为用户拖动的选区边界。

现在“自动选区”显示候选照片的矩形外接范围，确认后仍使用原候选的内部掩膜；用户重新框选后，按新的手动范围分析。片基取样仍用小椭圆表示取样区域。这里的范围指单张照片内容，不是整条底片；多张照片同框时仍自动选择一个目标。

这项修改解决显示与编辑方式的问题，没有把内部识别改成固定 135 矩形，也没有取消倾斜、弯曲形状的统计支持。如果原问题包含“选中了错误的照片或内容”，仍需原始问题画面复测；本轮所附图片是布局草图，不能据此验证真实边界准确率。

## 手动调整

打开“手动调整”后有两个可独立折叠的组：

| 分组 | 控件顺序与作用 |
| --- | --- |
| 校色 | Dmin / Dmax 影调端点 → 红、绿、蓝密度对齐 → 反相开关 → RGB 曲线；下方保留黑白覆盖、自动校色强度和静帧片基取样 |
| 基础 | 曝光 → 饱和度 → 对比度 → 白平衡色温 / 色调 → 中间调 |

RGB 对齐是在自动密度校正后增加单通道偏移，不改变取样片基本身。曲线有阴影、中间调、高光三个可上下拖动的控制点，黑白端点固定、输出保持单调，防止反转影调；可分别编辑 R / G / B，或以 RGB 入口应用共同曲线。曲线保留白点以上的高光余量。当前通道用强调色标记，可单独重置。

曲线和通道对齐进入原有密度查找表；基础对比度在显示阶段调整亮度，围绕线性 18% 中灰改变反差，不因基础滑块变化重新生成密度查找表。CPU 参考与 GPU 着色器都有相应处理；自动重新识别会清除这些旧手动偏移，避免影响新一次校正。

## 独立摄像头选择与异步保护

负片预览的摄像头列表是本工具自己的面板，不调用测光的“选择与管理摄像头”，也不写入测光摄像头偏好。进入工具时从测光镜头开始；退出后恢复测光原镜头。后台恢复时，如果临时镜头已不可用，回退到当前可用的测光镜头。

切换前截取最后显示的一帧，按原 TextureView 的比例和位置显示模糊图像，取景区中央显示旋转指示。显示图最长边先限制为 384 像素，再缩至不超过 96 像素进行三轮分离模糊，限制 UI 线程计算与持有内存；它只用于过渡，不参与片基识别。新摄像头第一帧到达后结束遮罩；12 秒仍无画面则结束等待并提供重试，保留选择其他摄像头的入口。横屏侧面板及左右手布局有各自的取景区计算。

切换会重建负片渲染器，使首帧回调属于新镜头。截图、自动识别和锁定的迟到回调使用操作序号过滤；退出、重新捕获或切镜头后，旧结果不能覆盖新操作。关闭页面释放过渡位图、取消超时和动画；重复打开列表不会累计已移除的主题控件引用。
