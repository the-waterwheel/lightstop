# 系统测光组合交互合并

2026-10-15。基线 `0f4f29f`。本轮只调整设置展示与选择入口。

## 用户看到的行为

- 两个原先并列的设置统一为一张“系统测光组合”卡片，第一排选择“系统预设”或“手动选择”。
- 系统预设下方紧接着显示“高精度 / 稳定 / 兼容”，共用同一张卡片，不再显示第二个设置标题。
- 手动选择时隐藏预设排，后续设置上移，滚动范围及无障碍目标同步更新。
- 从系统切到手动时沿用原有入口，立即开始组合选择流程；相机尚未完成初筛、正在测量等情况继续遵守原有检查。
- 手动已经选中时，再次点击仍可重新进入组合选择；重复点击不重写预设模式或触发普通设置变更。
- 切回系统预设时显示此前保存的预设模式。没有保存选择的新状态仍默认 SYSTEM / AUTO，即系统预设 / 高精度；保留用户此前明确保存的选择。

## 实现边界

`SettingsCatalog` 更新分组名称和选项标签；`SettingsView` 合并卡片、条件显示预设排，并为已选中手动的再次点击发出入口事件。触摸与无障碍点击共用处理逻辑。隐藏的预设不能通过上一帧残留的触摸目标触发；节点标识按设置及选项稳定分配，避免隐藏后把旧无障碍目标分配给其他设置。

`MeterLayout` 把首次选择和重复进入都交给既有 `onCombinationSelectionModeChanged`，保留从 Zone 退出后再进入组合筛选的顺序。`MainActivity`、CameraController、组合候选排序/过滤、HAL 探测、手动确认/取消、枚举及偏好存储键均未修改。校准和普通测光的选源算法不变。

## 验证

新增 10 项 Robolectric 交互/预览测试，覆盖：

1. 默认选中系统预设，三种预设紧接在下面。
2. 切到手动立即发出入口事件，并移除预设排的布局和无障碍目标。
3. 已选中手动时反复点击可以重进，不修改之前保存的预设。
4. 切回系统恢复先前模式，重建状态仍保留选择。
5. 重复点击系统预设不启动组合重选。
6. 无障碍点击可首次进入和重复进入手动。
7. 尚未重绘时，隐藏预设的旧触摸目标不能改动模式。
8. 隐藏后旧无障碍目标失效，不会误点其他设置。
9. 使用生产 MeterLayout 验证两次手动点击均打开既有组合选择界面；硬件探测用可控候选替代。
10. 中英文、明暗主题、系统/手动共 8 张原生 Canvas 预览，已检查分组、标签、间距和隐藏效果。
