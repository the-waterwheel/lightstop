# 胶片外观参考图源总索引

## 使用说明

本索引对应光档 LightStop v0.6.1 胶片数据库的285条内置记录，供胶片外观重绘和界面配图使用。按品牌、库内编号和型号排列，同一型号的多个图源及历史包装分别保留。

共收录697条型号与图源对应记录，涉及682个去重链接；275条胶片记录已有图片入口，10条仍列为缺图。图片入口不等于盒与暗盒均已配齐，也不等于全部版本已逐张确认。

摄影用135卷分别标记外盒与暗盒；120和220卷保留实际卷体及包装。电影片、航摄片与原料分装卷优先指向原厂盘片罐或大卷包装。页片保留页片盒，不虚构135暗盒。

外盒及暗盒表示前次搜集记录可见两者；包装及卷体表示照片有包装与卷体，但暗盒细节或规格需打开原图辨认。包装图型待核对不视为已确定盒或暗盒。原料盘片包装参考不等于品牌零售包装。

历史包装以图中文字为准。文件名中的old、new、年份及市场名称保留为来源标签，不单凭文件名确定年代。网页、分类页和拍卖页可能更换图片或失效；除明确标记的图型复核外，链接在线状态不作持续保证。
